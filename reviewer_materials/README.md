# Reviewer Materials

This directory contains the supporting data and analysis resources underlying the results presented in the associated manuscript.

## Contents

### `training_dataset/`

Original microscopy images and corresponding ground-truth segmentation masks used for training the StarDist models provided in the `models/` directory.

### `benchmarking/`

Python scripts used to evaluate segmentation performance and calculate the benchmarking metrics reported in the manuscript.

### `figure_source_data/`

Original source-data spreadsheets used to generate the quantitative figures presented in the manuscript.
