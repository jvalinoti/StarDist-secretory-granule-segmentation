# Reviewer Materials

This directory contains the supporting data and analysis resources underlying the results presented in the associated manuscript.

## Contents

* [`training_dataset`](./training_dataset) - Original microscopy images and corresponding ground-truth segmentation masks used for training the StarDist models presented in the manuscript (provided in the `workflow/` directory of this repository).

* [`benchamrking`](./benchmarking) - Python script used to evaluate segmentation performance and calculate the benchmarking metrics reported in the manuscript.

* [`figure_source_data`](./figure_source_data) - Original source-data spreadsheets used to generate the quantitative figures presented in the manuscript.
